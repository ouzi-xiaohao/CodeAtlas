# CodeAtlas 离线评测

运行：

```bash
python -m evaluation.run_eval
```

结果写入 `evaluation/results.json`。当前 v2 基准包含 62 个中英文知识片段、60 个检索问题、12 个研发领域和 15 个影响风险样例，覆盖代码定位、架构关系、历史 Issue、测试与字段影响。

指标定义：

- `Recall@K`：前 K 个结果覆盖的相关证据比例。
- `MRR`：第一个相关结果排名的倒数均值。
- `Precision@5`：前 5 个结果中相关证据的比例。
- `citation_recall`：回答引用覆盖金标准证据的比例。
- `citation_precision`：回答引用中属于金标准证据的比例。
- `NDCG@5`：同时衡量相关结果是否出现以及是否排在更靠前的位置。
- `Success@1`：第一条结果命中任一金标准证据的查询比例。
- 延迟为本机内存模式工作流耗时，不包括网络、真实 Embedding、Reranker、Qdrant、Neo4j 或模型生成耗时。

该数据集仍为模板化合成数据，只适合回归测试和发现明显问题，不应作为生产效果或容量结论。生产评测至少需要从真实仓库抽取 100～300 个经过研发人员标注的问题，并分别报告不同仓库、语言和问题类型的数据。
